# 🚀 九九ギャラクシー (KUKU GALAXY BLASTER)

こたえのブロックをえらんで撃ちぬく、奥行きスクロール型の九九れんしゅうゲームです。
ブラウザだけで動きます(インストール不要)。

## あそびかた

- `←` `→` : こたえのブロックをえらぶ
- `Space` または `↓` : いますぐ発射(はやいほどボーナス)
- `P` または `Esc` : ていし / さいかい(画面右上の ⏸ ボタンでも可)
- 🏠 ボタン : ホーム(メニュー)へもどる
- `Enter` : スタート / もういちど
- `M` : おと ON/OFF
- メニューで `1`〜`5` : レベルへんこう
- タブレット・スマホ: ブロックの下あたりをタップでえらぶ、もういちどタップで発射

### レベル(速さとこたえの数が連動)

| レベル | なまえ | こたえのブロック | スピード |
|---|---|---|---|
| Lv1 | はじめて | 2つ | ゆっくり |
| Lv2 | なれてきた | 3つ | ふつう |
| Lv3 | いちにんまえ | 4つ | はやい |
| Lv4 | たつじん | 5つ | とてもはやい |
| Lv5 | でんせつ | 6つ | さいそく |

レベルが高いほど、1問ごとの基本ポイントも増えます。
90%以上の正解率でクリアすると「つぎのレベルへ」ボタンが出ます。

### ルール

- 正解のブロックを選ぶと、ぜんぶ破壊しながら前に進みます。
- 連続正解でコンボがたまり、5コンボごとにポイントが ×2 → ×3 → … → ×5 にアップ。
- コンボが増えるとブロックが速くなります(最大で25%短縮)。
- まちがえるとコンボがリセットされ、ライフが1つ減ります(ライフ3つ)。
- 1ラウンドは20問。まちがえた九九は「にがて」として記録され、次から出やすくなります。
- 「れんしゅうモード」はライフなしで安心して練習できます。
